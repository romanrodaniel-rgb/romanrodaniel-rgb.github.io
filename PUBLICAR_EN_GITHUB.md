# Publicar ahora en GitHub Pages

Este paquete está preparado para la dirección gratuita:

https://romanrodaniel-rgb.github.io

## Pasos

1. En GitHub, crea un repositorio público llamado exactamente `romanrodaniel-rgb.github.io`.
2. Descomprime este ZIP en tu ordenador.
3. Dentro del repositorio, pulsa **Add file → Upload files**.
4. Arrastra el contenido interior de la carpeta: `index.html`, `styles.css`, `script.js`, `.nojekyll`, la carpeta `assets` y los archivos Markdown.
5. Confirma la subida con **Commit changes**.
6. Abre **Settings → Pages**.
7. En **Build and deployment**, selecciona **Deploy from a branch**.
8. Elige la rama `main`, carpeta `/ (root)` y pulsa **Save**.
9. Espera unos minutos y abre `https://romanrodaniel-rgb.github.io`.

No configures todavía **Custom domain**. El paquete no incluye un archivo CNAME para evitar que GitHub intente redirigir prematuramente a romanrodaniel.com.

Más adelante puedes conectar `romanrodaniel.com` sin cambiar la web, siempre que mantengas registrado el dominio.
